# About Cribliv

Cribliv is building the verified rental layer for North India. We:

- Verify every listing's owner via Aadhaar + property documents.
- Give tenants a **12-hour refund guarantee** on confirmed bookings.
- Use AI to rank listings by fit (commute, budget, lifestyle).
- Surface PGs, flats, and houses in the same search experience.

## Coverage

- Delhi NCR (Delhi, Gurugram, Noida, Ghaziabad, Faridabad)
- Chandigarh
- Jaipur
- Lucknow (deepest coverage — locality + landmark + metro level)
